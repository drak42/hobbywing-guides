# Hobbywing Guides

Setup and settings guides for Hobbywing crawler power systems: specifications, every programmable
setting with its factory default and **LED Program Box codes**, what each setting does, and
recommendations for **trail** and **crawling**.

## Products

| Guide | Type | Programmed with |
|---|---|---|
| [QuicRun Fusion Pro](docs/fusion-pro.md) | 2-in-1 brushless motor/ESC, 2300 kV, 2–3S | LED Program Box |
| [QuicRun Fusion Pro Elite](docs/fusion-pro-elite.md) | 2-in-1 brushless motor/ESC, 2300 kV, 2–4S | LED or LCD Program Box |
| [XeRun AXE R2](docs/axe-r2.md) | Brushless ESC + AXE R2 motor, FOC, 2–3S | HW Link V2 app (Bluetooth) only |
| [QuicRun WP 1080 G1 and G2](docs/quicrun-wp-1080.md) | Brushed crawler ESC, 80 A, 2–3S | SET button or LED Program Box |

## General guides

- [Programming Tools](docs/programming-tools.md) — LED Program Box, LCD Program Box Pro/G2 and the
  HW Link V2 Bluetooth app: what works with what, how to connect, how to read the LED box, and
  throttle calibration.
- [Settings Explained](docs/settings-explained.md) — running modes, drag brake, punch, RPM matching
  and the rest in plain terms.

Specifications, settings and defaults come from Hobbywing's own user manuals (linked in each guide).
Recommendations are starting points from the manuals and community experience — change one setting at
a time and test.
